# Community Code of Conduct

MacroPad Studio welcomes respectful, technically grounded participation.

## Expected behavior

- Be constructive and specific in issues, reviews, and discussions.
- Respect differing experience levels and ask clarifying questions in good
  faith.
- Focus criticism on code, evidence, design, and safety rather than people.
- Protect personal information and unpublished security details.
- Disclose uncertainty, especially when hardware behavior has not been
  physically verified.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, deliberate disruption, and
publishing private security reports are not accepted.

## Enforcement

Repository maintainers may edit or remove content and temporarily or
permanently restrict participation when needed to protect contributors and the
project. Report conduct concerns privately through the repository owner's
GitHub profile or another private maintainer channel.
