# MacroPad Studio 0.1.0

MacroPad Studio is a native macOS configurator for supported
`MINI_KEYBOARD` USB macro pads.

> [!WARNING]
> The attached macOS ZIP is ad-hoc signed and **not notarized by Apple**.
> Gatekeeper may block it. This artifact is provided as a pre-release build
> for technical evaluation; build from source if you do not accept that risk.

## Highlights

- Native SwiftUI editor for three keys, one knob, and three layers.
- Read and write support for the physically validated `1189:8840` device.
- Keyboard sequences, media controls, mouse actions, and layer lighting.
- Direct keystroke recording with dropdown controls as a fallback.
- Explicit change review before every hardware write.
- Local drafts and an interactive demo mode.

## Validated hardware

| USB VID:PID | Layout | Read | Write |
| --- | --- | --- | --- |
| `1189:8840` | 3 keys, 1 knob, 3 layers | Yes | Yes |

Devices with the same product name may use incompatible protocols. Do not use
write support unless the exact VID:PID and physical layout match.

## Requirements

- macOS 14 or later
- A direct USB connection for reading and writing
